# Akanksha Bhardwaj – Portfolio (Vite + React + TypeScript)
    npm install
    npm run dev        # local dev server
    npm run build      # type-check + production build in /dist

Edit content in `src/config.ts`: links, email, skills, projects, timeline.
Resume: put the PDF at `public/resume.pdf`, then set `resumeUrl: "/resume.pdf"` in config. Until then the button shows a placeholder notice.
